# Extra skin-invloeden — 0.4.0

De gebouwde desktopapp kapt FBX-gewichten niet meer af op vier. `scripts/extended-loader-patches.mjs` past de gepinde Three.js FBX-loader tijdens bundelen aan: maximale control-point-stride, triangulatie met die stride en uitvoer naar vier-componentensets. De glTF-loader leest JOINTS_n/WEIGHTS_n al, maar normaliseert standaard alleen set 0; ook die normalisatie wordt uitgesteld. Structurele assertions stoppen de build als de verwachte loadercode verandert.

`src/core/skinning.js` valideert alle sets en normaliseert hun gezamenlijke som. Set 0 gebruikt `skinIndex`/`skinWeight`; aanvullende sets gebruiken glTF-semantische namen `joints_n`/`weights_n`. Daardoor behouden geometriecompactie en de GLB-export alle data zonder eigen opaque sidecar. Genormaliseerde integer-accessors worden via getComponent als echte gewichten gelezen.

Voor meerdere sets worden per vertex twee RGBA32F-texels per set opgeslagen: vier jointindices en vier gewichten. De vertexshader leest deze met gl_VertexID, berekent de volledige gewogen botmatrix en gebruikt die voor zowel positie als normal/tangent. Er zijn geen extra vertex-attributen nodig voor elke groep van vier. Een cache per geometrie houdt de texture vast; geometry disposal ruimt haar op. Materialen krijgen per mesh uniforms om verwisseling bij gedeelde materialen te voorkomen. De CPU applyBoneTransform, diagnostiek, anatomische regioselectie en donor-retargeting gebruiken dezelfde volledige sets. Gekloonde/geconverteerde/atlas-meshes worden opnieuw geconfigureerd.

Grenzen: maximaal 256 sets (1024 opgeslagen invloedplaatsen per vertex), geldige botindices en positieve totale gewichten. De influence-texture moet binnen de echte GPU-maximale textuurafmetingen passen; anders volgt een fout. Dual-quaternion skinning, FBX additive-clustersemantiek en alle mogelijke FBX-deformers zijn niet geïmplementeerd. Het aantal invloeden zegt niets over correcte bron-bindposes of Tekken-animatiecompatibiliteit.

`npm run test:skinning` maakt eigen FBX-versies 7400, 7500 en 7700 met twaalf gewogen clusters, controleert de bijdrage van de twaalfde bone, importeert een twaalf-invloeden-GLB, vergelijkt de GPU met een ongeskinned CPU-referentiemesh en controleert reductie/GLB-roundtrip. Deze fixture is geen Nikki- of Nina-bestand. De enginefuncties worden aanvullend in unit-tests gecontroleerd, inclusief clone-behoud en donor-retargeting.
