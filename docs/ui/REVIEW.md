# Conversion Studio 0.7.0-dev.9-ui.1 — UI review

A separate presentation workflow based on the tested dev.9.1 conversion engine. Main and earlier releases are unchanged. No conversion algorithm, preset parameters, native codecs or project schema were changed.

The new dark workspace combines restrained glass-like gradients, cool silver/turquoise borders and small digital accents. No heavy blur, downloaded fonts or continuous UI effects. The default view prioritizes model import, style, detail, retro textures, conversion and preparation export. Technical controls are grouped into nine searchable accordion categories. Standard/advanced modes, preview layout and panel preferences persist locally without storing private assets or resetting model settings. Multiple open categories require an explicit choice.

All 80 original ID-bearing controls are retained exactly once; the report contains their original inventory and new destinations. The actual UI test covers two-model import/switching, preset changes, conversion, decoded preparation export, real project save/reopen, mode changes, customized preset indicators, search, Escape/focus return, Enter activation, multiple accordions, all four preview layouts, presentation preference reload and reduced motion. It checks 1366×768, 1920×1080 and 2560×1440 for horizontal overflow, preview size and above-fold beginner actions.

The Windows release workflow requires the full test suite, actual desktop IPC, skinning/mapping/native fixtures, the portable EXE smoke test, the private Nikki roundtrip with all 24 byte-identical assets, the UI test in the packaged app, both bake modes and a real offline Edge file:// report test. Download publication occurs only after all these gates succeed. Reports use authored synthetic characters, not private source models. The private Nikki project and original assets are excluded from artifacts and releases.

Extract UI-Review.zip and open index.html. Click any screenshot for full resolution. Old/new cloud comparisons use the same synthetic model; separately labeled Windows screenshots may differ in fonts/antialiasing. Conversion report labels and technical controls remain partly English. This UI release does not solve the remaining hand/clothing reconstruction limits or establish Tekken 3/Expanded gameplay compatibility. Human design and artistic approval remain pending.
