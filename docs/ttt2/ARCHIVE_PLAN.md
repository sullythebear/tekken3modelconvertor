# Local-only TTT2 archive workstream

Source: upstream archive.py at6510de48b137c526debcfddebd6a4813fc65f631 (MIT notice already bundled). Inspected before implementation. OFS is big-endian size/tag chunks; ofsi contains key/word records, ofsd contains N+1 encoded offsets. BIN payload starts0x100; low nibble encodes entry length modulo16. Entries use four keyed LCG XOR streams, optionally NRCZ+declared-size+flags+zlib. Most-recent numbered archive overrides matching keys; every source remains browsable. Source archive index has no original filenames or dependency graph.

Name search computes the upstream CRC convention and confirms magic, not inferred character IDs or proximity grouping. Generic code+'.nud/.nut/.bon' lookup is evidenced by convert/skin.py (SHARED containsjin). Display candidates as such, never proven names. Pack member base4 CRC continuation is implemented as a utility, but no guessed pack naming/association. Raw asset type is verified by decoded NDP3/NTP3/BONE magic. No raw BIN brute-force search for coincidental strings.
